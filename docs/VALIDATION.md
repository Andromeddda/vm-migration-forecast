# Проверка локального deployment — 11.11.2026

Проверено на Linux x86_64 с uv 0.13.6 и скачанным uv-managed CPython 3.11.14.
Проверки не использовали учётные данные участника.

| Проверка | Результат |
|---|---|
| Восстановление исходного uv.lock со всеми extras | 126 зависимостей установлены; lock не изменялся |
| `uv pip check` | Все установленные зависимости совместимы |
| Pytest | 36 тестов успешно, включая 20 существующих domain/data tests |
| Начальная загрузка без site-packages | Settings импортируется без NumPy/Google SDK |
| Все code cells трёх notebook | Успешно выполнены в отдельных Python-процессах, без сети для extraction |
| Реальный Jupyter на localhost:8888 | HTTP API отдаёт 3 notebook с токеном; без токена доступ отклонён |
| Остановка Jupyter | Сервер остановлен; побайтовые hash исходников не изменились |
| gcloud standalone x86_64 | Официальный versioned archive скачан, SHA-256 проверен, `version` → 593.0.0 |
| gcloud arm archive | SHA-256 вычислен по официальному versioned HTTPS archive; выполнение на ARM не проверялось |
| Source hygiene / shell syntax | Текстовые исходники, notebook outputs очищены, `sh -n lab` |

Дополнительно проверены literal dotenv без shell evaluation, приоритет env над файлом,
отказ на неизвестные/дублированные ключи, запрет source-runtime paths и symlink escape,
непересекающиеся runtime-каталоги, атомарный private config, проверка диска до
установки, занятого порта, безопасное распаковывание CLI и отказ при неверном hash.
`install-gcloud` автоматически записывает путь CLI, без ручного переноса значения.

## Не объявляется проверенным

- OAuth в браузере участника, IAM/Sandbox и реальная выгрузка BigQuery не выполнялись.
  Платные SQL не запускались. Query budget проверяется fake client.
- Выполнение через настоящий Jupyter kernel/nbclient в этой среде ограничено:
  kernel завершался при запрещённом системном обнаружении сетевых интерфейсов
  (`Operation not permitted`, libzmq). Код ячеек проверен отдельно, HTTP-сервер —
  отдельно. Команда `verify-notebooks` сохранена для обычной локальной машины;
  она выполняет копии и принудительно выключает Google-подключение/SQL execution.
- Нативное исполнение ARM, другие Linux-дистрибутивы, musl и старые libc не проверялись.
  Отсутствие привязки к пакетному менеджеру — свойство скриптов, а не доказательство
  полной аппаратной совместимости.
- `audit` проверяет известные шаблоны; произвольный секрет нельзя гарантированно
  распознать регулярными выражениями.

Результаты прежней инфраструктуры не используются как доказательство нового запуска.

## Обновление правил Sandbox — 11.11.2026

Из auth удалены проверка обязательного биллинга и set-quota-project.
ADC создаются с --disable-quota-project. Регрессионный тест отклоняет обращения
к billing и set-quota-project. Диагностика не предлагает включать оплату.
OAuth и запросы с аккаунтом участника не выполнялись.
