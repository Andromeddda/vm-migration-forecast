# Правила проекта

## Google Cloud — только BigQuery Sandbox

- Использовать проект без подключённого биллинга.
- Работать в пределах бесплатной квоты BigQuery Sandbox: 1 ТиБ обработанных запросами данных в месяц.
- Не привязывать платёжный аккаунт или карту.
- Не включать бесплатный пробный период, Free Trial или Upgrade.
- Не включать в сценарий регистрацию или авторизацию по номеру телефона.
- Если Google требует карту или телефон, остановить настройку; не предлагать переход на платный режим.
- При исчерпании квоты ждать её обновления или сокращать объём эксперимента.
- Не устранять ошибки доступа и квот подключением биллинга.
- Применять эти ограничения ко всем будущим инструкциям, скриптам и экспериментам.

Документация Google: https://docs.cloud.google.com/bigquery/docs/sandbox

- Оформлять требования и перечисления списками.
- Не объяснять очевидные placeholders.

## Развёртывание

- Выполнять код локально на Linux; открывать Jupyter на localhost:8888.
- Не использовать инфраструктуру Colab, монтирование Drive или rclone.
- Хранить в проекте только текстовые исходники без персональных настроек и секретов.
- Создавать окружение, конфигурацию, данные и отчёты вне каталога исходников.
- Не создавать и не инициализировать git без отдельного указания пользователя.
